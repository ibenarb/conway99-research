# C2 calibration 1.0.0, 2026-09-14

Scope: compare eight exhaustive cubes with three unpartitioned baseline controls. No new exclusion is claimed by this package. The partition rationale and coverage proof are pinned at d626759789a200b81e9df889429262593753cf0c. Thakkar arXiv:2608.11211 does not provide a general involution exclusion; this experiment targets the separately documented full C2 model.

Default: 11 concurrent solver processes, 3600 seconds requested per solver, external wall watchdog at 3660 seconds per process. Eight cube jobs use seed 0; baselines use seeds 0,1,2. Every job writes ASCII LRAT with the same CaDiCaL flags. This is a bounded calibration, not a time limit for the eventual exclusion campaign. No automatic overnight continuation. Status reports every ten minutes include wall-clock UTC as well as monotonic time, per-job proof sizes and resources. Exact completion time is unknown if production proofs need verification.

The start command launches a detached controller; startup validation and real tiny UNSAT-positive / SAT-negative proof-checker controls precede production. The existing prepared baseline and variable map are hash-pinned. All eight cubes are rebuilt and read back, so external edits to cube manifests cannot alter coverage. Each job gets its own input copy and commands, hashes and PID in jobs.json. No existing user process or old proof is modified. Requires approximately 0.8 GiB additional CNFs plus growing proofs. The previous unpartitioned portfolio grew approximately 40 GiB/hour; this is not a guaranteed forecast for the new jobs.

Resource checks every two seconds stop owned solver processes below 75 GiB disk free or 2 GiB MemAvailable. Solver outputs, partial proofs, statuses and completed small logs are retained. Interruptions record partial states where possible; a host crash can still leave stale RUNNING records. The launcher itself reports launch only, not successful startup.

After all solvers finish, UNSAT answers with exit 20 and corresponding status are checked sequentially by Cake against their individual augmented CNFs. Input and proof hashes are checked; strict success requires exit 0, stdout exactly s VERIFIED UNSAT, and empty stderr. No production checker wall limit. An UNSAT-certified baseline suffices for the baseline formula; otherwise all eight certified cubes are required. The fixed-frame and encoder arguments remain external proof obligations for a C2 interpretation. All production raw proofs and CNFs are retained for independent replay.

SAT answers are reconstructed and tested by the pinned reference graph checker, including the cube assumptions. A SAT graph is a stronger result but must be inspected and archived independently. Timeouts are open, never exclusions. A solver error does not stop other jobs, but is retained as an error. A failed proof check cannot contribute to closure.

Implementation reuses unchanged source pilot.py and c2_reference.py from the verified v1.1 package for tiny controls, strict Cake verification and graph validation. The new coordinator never invokes pilot.run. prepare_partition.py is unchanged from the previous commit. Test results are five explicitly simulated eleven-process transitions: all open, one certified cube only, all eight certified cubes, a certified baseline, and checker rejection. These tests are not actual certificate verification; real control checks run on the Ryzen. Mathematical performance remains unmeasured.

Launch: python3 calibrate.py. Default prepared input is partition_20260914_203703_421425 under ~/conway99_workspace/c2_reference_v1. Optional --base, --out, --seconds. Main output: driver.log, inputs.json, jobs.json, status.json, snapshots, each job/result.json, summary.json. This commit adds no scheduled external action or automatic publication of local results.
